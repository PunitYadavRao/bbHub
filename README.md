# BBhub

BBhub's web app, built with Next.js (App Router), TypeScript and Tailwind CSS.

The site currently shows a coming-soon page.

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm run lint
```

## Structure

- `app/layout.tsx`: root layout, fonts and metadata
- `app/page.tsx`: coming-soon landing page
- `app/globals.css`: Tailwind and theme tokens
